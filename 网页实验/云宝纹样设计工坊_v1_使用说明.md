# 云宝二方连续纹样 AI 实验平台 v1.5

## AI 协同形态

- 平台顶部新增“AI 智能体”入口，在平板横屏上以右侧抽屉打开 EduFlow 的“云宝二方连续纹样学习与创作助手”。
- 学生始终在实验平台完成教材观察、创意输入、规则执行、纹样可视化、云宝试穿、结果核对和证据导出；AI 只负责追问、澄清与提示。
- AI 对话与本地实验画布目前不自动同步。学生须把最终确认的创意原话填写到平台输入框，并核对画布结果；页面已明确提示这一边界。
- 内嵌页已验证可以进入上海市教育统一身份认证；因为平台与 EduFlow 域名不同，每位学生首次使用时可能仍需在抽屉中登录。若学校浏览器限制内嵌登录，可使用“在新窗口打开”作为兼容入口。

## 本次试用后修订

- 第4步增加硬门槛：必须在第3步完成“创意—平台理解—当前设计”对照并确认设计，不能从顶部导航跳过。
- 教材规律说明必须先选定表1的一条具体纹样，再说明其单位图案、方向、变换和延伸方法；通用套话不再过关。
- 创意解释器改为按学生语句中的“颜色＋图案”成对识别，例如“绿色星星和红色叶子”不再交换颜色。
- 展开的纹样带显示实际生成箭头，向左、向右和向左右两侧不再只改文字。
- 作品自检按当前图案、方向和变换规则检查具体性；“1”等无意义内容不能通过。
- 同伴续画改为“同伴编号＋续画结果＋具体记录”，学生自检通过不等于教师评价通过。
- JSON 与 SVG 导出后明确提示“仅保存在本机，尚未提交给教师”。

## 课堂定位

学生先完成教材学习区，再进入迁移创作区。教材学习区只落实教材与教参明确提出的内容：理解二方连续纹样的定义，识别单位图案及其变换方式。给学校吉祥物“云宝”设计衣服纹样，是基于教材内容改编的迁移任务，不是教材原题。平台在学生表达创意后，再将其转换为可编辑的单位图案、颜色、变换方式和间距。

## 学习闭环

1. 学习纹样：对照教材定义，识别单位图案、排列方向和变换方式。
2. 说出创意：支持文字和浏览器语音识别；此时平台不先生成方案。
3. 平台实现：核对平台理解，调整图案、颜色、变换方式和间距。
4. 说明规律：说明单位图案、排列方向和变换方式，并请同伴根据说明续画。

## 教材边界

| 层级 | 本平台如何处理 |
| --- | --- |
| 教材明确内容 | 二方连续纹样的定义；单位图案；沿上下或左右方向连续排列；平移、旋转、轴对称等变换方式。 |
| 教参明确要求 | 活动1重点引导学生找出单位图案，并识别所采用的变换方式。 |
| 平台改编任务 | 给云宝设计服装纹样、语音表达创意、颜色和间距调节、虚拟试穿、作品导出。页面均标为“迁移创作区”或“创作参数”。 |
| 本平台不单列考查 | “最小单位”“固定距离”“形状大小不变量”“数学证明”等未被本课教材、教参明确列为活动1直接目标的表述。它们不进入学习关卡的必答条件。 |

## 当前原型边界

- 创意解释与纹样生成仍使用本地受限规则，页面如实标注“智能体追问＋本地规则执行”，不把确定性画布宣传成大模型生成。
- EduFlow 智能体已经接入同一平台界面，用于学习追问和创意澄清；智能体不直接改写画布参数，因此学生核对步骤仍是必需的。
- 页面使用学校提供的云宝PDF提取的透明图像；服装外形和纹样试穿效果是本平台生成的课堂原型。
- 学生记录默认保存在当前浏览器，可导出 v1.4 JSON；班级在线回收尚未接入新版数据结构。

## 教材对应

- 教材活动1要求学生从二方连续纹样中找出单位图案及其变换方式；平台前两关据此设计。
- 教材末尾小组活动包含自主设计并请同伴推测构图规律。平台借用这一活动结构，将情境改编为“给云宝设计服装纹样”，但不把改编情境说成教材原题。
- 教参将“识别单位图案”和“识别几何变换方式”列为活动1的直接意图，因此平台用识别练习与规律表达作为学习证据。
- 学习区直接使用教材第137页表1的四条二方连续纹样：第一行作为教材示范，后三行用于识别单位图案与变换方式。
- 云朵、星星、颜色、间距、虚拟试穿和导出只属于迁移创作区，不进入教材识别任务。

## 启动

双击项目根目录中的 `双击启动_云宝纹样设计工坊.command`，或直接打开 `云宝二方连续纹样设计工坊_v1.html`。

## 建议收集的课堂证据

- 学生创意原话；
- 平台的首次解释及假设；
- 学生手动修改的平台创作参数；
- 学生对平台实现的判断与修订说明；
- 学生对单位图案、排列方向、变换方式的说明，以及同伴续画记录。
