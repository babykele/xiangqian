# 初中数学新课标 Skill 使用手册

本手册说明如何调用这套从《义务教育数学课程标准（2022年版）》蒸馏出的 8 个 skill。

---

## 一、这套工具解决什么

不追专家、不追热词，直接把课标的方法论"提纯"成可复用工具。技术会变，但课标规定的
核心素养、学业质量、单元设计逻辑、跨学科主题学习的底层逻辑是稳定的地基。这套 skill
就是把地基变成随手可调的工作流。

## 二、在哪里、怎么被调用

- 位置：`~/.workbuddy/skills/` 下 8 个 `mathcs-` 开头的目录，每个含一个 `SKILL.md`。
- 调用：在对话里**直接点名 skill**，或**说清任务**让 agent 自动匹配。
  - 精准召回技巧（重要）：想让它稳定命中某个工作流，**直接叫出 skill 的名字**，
    例如"用**跨学科项目式学习设计器**帮我设计一个八年级一次函数的项目"。
  - 或："请用我蒸馏义务教育数学课程标准的工作流来修改这份教案。"

## 三、8 个 Skill 用法速查

### 1. 数学核心素养对标器
- 何时用：拿不准一节课/一道题到底培养什么素养；给教案做素养体检。
- 怎么说："这节'一次函数图象'主要培养哪些核心素养？"／"帮我核对这份教案的素养标注。"
- 会得到：主素养(1-2)+次素养、匹配依据、"哪个会"的落点；体检模式逐条 ✅/⚠️/❌。
- 特色：严守初中9表现(抽象能力/运算能力/几何直观/空间观念/推理能力/数据观念/模型观念/
  应用意识/创新意识)，自动纠正"数感、推理意识"等**小学词越级**错标。

### 2. 素养导向教学目标生成器
- 何时用：写教案/公开课定目标。
- 怎么说："帮我写'二元一次方程组'第1课时的教学目标。"
- 会得到：2-3条挂素养、含过程目标、主语是学生、动词规范的目标 + 四基四能落点 + 评价证据。

### 3. 结构化单元整体设计器
- 何时用：做大单元设计、单元复习统整。
- 怎么说："帮我做'一次函数'单元整体设计。"
- 会得到：领域主线定位、知识结构关联图、生长点/延伸点、单元目标→课时地图(体现进阶)。

### 4. 真实情境与问题链设计器
- 何时用：设计导入、探究活动、情境化问题。
- 怎么说："给'相似三角形'设计一个真实情境和问题链。"
- 会得到：情境(标来源)、认知冲突、3-5步递进问题链(标⭐抽象跃迁点)、数学化路径。

### 5. 跨学科项目式学习设计与论文投稿器 ★你最关心的（双模式）
**模式A · 设计项目**
- 何时用：综合与实践、项目式学习、跨学科主题、课题申报。
- 怎么说："设计一个融合地理的初中数学项目式学习。"
- 会得到：选题四问自检、驱动问题、问题数学化、学科整合点、项目流程、核心模型、
  物化成果、过程性评价量规。
- 内核：**用其他学科的方式方法，解决本学科的真实问题**。

**模式B · 成果论文化投稿**（投《中学数学教学参考》/《上海中学数学》）
- 何时用：把已完成的项目/教学案例改写成可投稿的教学实践论文。
- 怎么说："把这份齿轮探究案例改成投《中学数学教学参考》的论文。"
- 会得到：符合刊物体例的全文——标题(带"——以…为例")、150~250字摘要、关键词、
  1/2/3分节正文(问题提出→设计实施→成效→反思)、图表编号、GB/T 7714 参考文献(必引课标)，
  外加一份"投稿自检清单"(摘要长度/关键词/分节统一/文献规范/匿名送审/成效不夸大等)。
- 依据：对标真实样文(《中学数学教学参考》下旬)提炼的体例，成效表述强调"有边界、不夸大"。

### 6. 教学评一致性与学业质量对标器
- 何时用：设计评价环节、单元量规、命题双向细目、作业设计。
- 怎么说："帮我把这份教案做教学评一致性检查。"／"按第四学段学业质量给这套题做多维细目。"
- 会得到：教—学—评对齐表、评价量规、命题细目(素养立意/真实情境/主观题≥客观题)。

### 7. 课标内容精准检索器 ★解决"概念召回精准"
- 何时用：备课查依据、核对教案的课标出处、依标命题。
- 怎么说："课标里'二次函数'的内容要求和学业要求是什么？"
- 会得到：领域>主题>条目三级定位、内容要求/学业要求/教学提示分列、水平动词标注、
  选学提示、关联素养、以及"需核对原文"的诚实提醒（**绝不编造条目**）。

### 8. 信息技术融合设计器
- 何时用：数字化教学、数学实验、混合式教学设计。
- 怎么说："'函数图象'这节课怎么用技术做数学实验？"
- 会得到：融合点定位、技术选型(附理由)、数学实验步骤、线上线下衔接、
  "技术不替代思维"的边界提醒。

## 四、组合成工作流（把单个工具串起来）

- 完整备课：7查依据 → 1定素养 → 2写目标 → 3单元定位 → 4情境问题链 → 8技术融合 → 6评价对齐
- 跨学科项目：5设计 → 1核对素养 → 6配评价量规
- 教案体检：1素养体检 → 7依标核对 → 6教学评一致
- 命题作业：7依标 → 6素养立意+多维细目

一句话触发整链："请用我蒸馏义务教育数学课程标准的工作流，帮我把这份〈课题〉的教案从
素养对标、目标、情境问题、到评价，完整过一遍。"

## 五、使用注意

- 这套 skill 基于**你上传的课标文件**蒸馏，与具体教材版本无关；教材更新不影响它，
  因为它对标的是国家课程标准的底层逻辑。
- 概念召回以课标为准：第7个"检索器"在不确定时会提示核对原文，请勿要求它"背出"
  不存在的条目编号——这是为保证准确性而设的护栏。
- 想扩展/修改：直接编辑对应目录下的 `SKILL.md` 即可。
